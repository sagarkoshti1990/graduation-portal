1. Logging In

The GBL Admin Console is the management portal for Supervisors and Administrators. It is accessed from the same URL as the field staff portal, but using the Login as Admin / Supervisor button.

Admin login screen — use 'Login as Admin / Supervisor' button

How to Log In

  1. Open a web browser and navigate to brac-qa.tekdinext.com
  2. Enter your Username / Email (work email address)
  3. Enter your Password
  4. Click "Login as Admin / Supervisor" — do NOT use the LC/LF button
  5. You will be directed to the User Management dashboard
⚠ Important: Always use "Login as Admin / Supervisor". Using the wrong login button will give you limited LC/LF access instead of admin access.
💡 Tip: If you see "Welcome back, [Name]" with a My Participants card, you used the wrong login button. Log out and try again.

4. Adding New Users

New users can be added one at a time or in bulk via CSV. Click the Bulk Upload (CSV) button in the top right of the User Management page.

Upload Users modal — choose between CSV bulk upload or single user

Option A: Add Single User

  1. Click Bulk Upload (CSV) in the top right corner
  2. Select "Add User" — manually add a single user
  3. Fill in the user's details (name, email, role, province)
  4. Click Save to create the account
  5. The user will receive an email with login credentials

Option B: Bulk Upload via CSV

  1. First download the template from CSV Import Templates in the sidebar
  2. Fill in the CSV with all users following the required format
  3. Click Bulk Upload (CSV) → select "Upload CSV"
  4. Choose the completed CSV file from your computer
  5. Review the import preview and confirm
ℹ Fields required when adding a user: Full Name, Email (unique), Role, Province. Phone number and site are optional.

5. Editing a User

You can edit any user's details by clicking the three-dot actions menu on their row.

Three-dot actions menu showing View Profile, Edit, and Deactivate options

Edit User modal — update name, province, and role details

How to Edit a User

  1. Find the user in the User Management list (use search/filters if needed)
  2. Click the ⋮ (three-dot) menu on their row
  3. Select "Edit"
  4. Update the relevant fields: Full Name, Province, District/Municipality, or Role
  5. Click Save to apply the changes

6. Viewing a User Profile & Deactivating

The View Profile option gives a read-only summary of a user's details, activity, and permissions.

How to Deactivate a User

  1. Find the user in the User Management list
  2. Click the ⋮ menu on their row
  3. Select "Deactivate" (shown in red)
  4. Confirm the deactivation in the prompt
  5. The user's status will change to Deactivated (shown with a red badge)
⚠ Note: Deactivated users cannot log in but their data is preserved. You can reactivate them later if needed.

7. Assigning LCs to Supervisors

Use the Assign Users section to link Linkage Champions to their supervising Supervisor. Navigate to Assign Users → LC to Supervisor tab.

Assign Users — LC to Supervisor tab: select province and supervisor to assign LCs

How to Assign an LC to a Supervisor

  1. Click Assign Users in the left sidebar
  2. Make sure the "LC to Supervisor" tab is selected
  3. Use the All Provinces dropdown to filter by province
  4. Use the Choose Supervisor dropdown to select the supervisor
  5. The system will display available LCs to assign
  6. Select the LC(s) and confirm the assignment
ℹ Why this matters: LCs must be assigned to a supervisor before they can be supervised. Unassigned LCs will not appear in any supervisor's caseload view.

8. Assigning Participants to LCs

Use the Participant to LC tab to link individual participants to their Linkage Champion.

Assign Users — Participant to LC tab: select supervisor first, then choose Linkage Champion

How to Assign a Participant to an LC

  1. Click Assign Users in the left sidebar
  2. Select the "Participant to LC" tab
  3. Choose the Supervisor first to narrow the list
  4. Then choose the Linkage Champion from the dropdown
  5. The system will show participants available for assignment
  6. Select participant(s) and confirm
💡 Tip: Always select the supervisor first — this filters the Linkage Champion list to show only LCs under that supervisor, making it easier to find the right person.

10. Bulk User Upload

After preparing your CSV file, use the Bulk Upload feature on the User Management page to import all users at once.

  1. Go to User Management and click Bulk Upload (CSV)
  2. Select "Upload CSV" from the modal
  3. A file picker dialog will open — select your completed CSV file
  4. The system validates the file and shows a preview of users to be imported
  5. Review any warnings or errors highlighted in red
  6. Click Confirm Import to complete the upload
  7. Users will receive welcome emails with temporary passwords
🚨 Before uploading: Double-check email addresses — they cannot be changed after account creation. Also verify role names are spelled exactly as required.

13. Admin vs Supervisor Roles

Both Admins and Supervisors use the same console login, but have different levels of access.

🔴 Admin (BRAC Admin / UAT Admin)

  • Full access to all 326 users regardless of province
  • Can add, edit, deactivate ANY user
  • Can reset passwords for ALL roles
  • Access to CSV Import Templates
  • Access to Password Management Policy
  • Access to Profile Field Edit Permissions
  • Can assign any LC to any Supervisor
  • Can assign any Participant to any LC

🟡 Supervisor

  • Access limited to users in their district
  • Can edit/deactivate LCs and Participants in their district
  • Can reset passwords for their LCs and those LCs' participants
  • Can assign LCs and Participants within their district
  • Cannot access CSV Templates, Password Policy, or Profile Permissions pages
  • Cannot modify other Supervisors or Admins
ℹ Summary: Supervisors manage their district team. Admins manage the entire system. When in doubt about a user issue, escalate to an Admin.

14. Tips & Best Practices

Daily Checklist for Supervisors

  1. Log in using Login as Admin / Supervisor button
  2. Check User Management for any newly Deactivated users that need follow-up
  3. Verify new Linkage Champions are assigned to your supervision (Assign Users)
  4. Ensure new participants are assigned to the correct LC (Assign Users → Participant to LC)
  5. Log out securely when done
